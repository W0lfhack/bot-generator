# bot-generator

Telegram-бот, который генерирует изображения по текстовому запросу с помощью **локально запущенной** генеративной модели.

## Зачем этот проект

Мне было важно не «прикрутить готовое API», а разобраться, как генеративная модель устроена и обучается изнутри. Поэтому проект я начал не с бота, а с фундамента: пишу генеративную модель с нуля на PyTorch, без готовых решений — так, чтобы понимать каждый шаг пайплайна обучения.

Бот — это конечная точка: пользователь отправляет запрос, модель отрабатывает локально, бот возвращает изображение.

## Текущий статус

Проект в активной разработке. Что сделано на данный момент:

- **Генератор** (`100 → 256 → 512 → 1024 → 784`, LeakyReLU в скрытых слоях, Tanh на выходе) — написан и отлажен
- **Дискриминатор** (`784 → 1024 → 512 → 256 → 1`, LeakyReLU в скрытых слоях, Sigmoid на выходе) — написан и отлажен
- Forward pass проверен на MNIST, размерности сходятся

В работе:

- Цикл обучения: оптимизаторы, BCELoss, шаг обучения генератора и дискриминатора
- Логирование метрик и сохранение чекпоинтов
- Инференс и обвязка Telegram-бота (aiogram)

## Стек

- Python 3
- PyTorch — модели и обучение
- torchvision — датасет MNIST и трансформации
- aiogram — Telegram-бот (в планах)

## Структура

```
.
├── models/          # генератор и дискриминатор

```

## Запуск

```bash
git clone https://github.com/W0lfhack/bot-generator.git
cd bot-generator
pip install -r requirements.txt
python train/train.py
```
